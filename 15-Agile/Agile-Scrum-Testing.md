# 🔄 Agile / Scrum Testing

## QA Activities in a Sprint

- Participate in requirement and refinement discussions.
- Review acceptance criteria and identify testable conditions.
- Prepare test scenarios and test cases.
- Prepare test data and environment requirements.
- Execute smoke and functional testing during development.
- Raise defects in Jira with complete evidence.
- Retest fixes and perform impacted regression.
- Communicate test status and release risks.
- Support sprint review and retrospective with QA observations.

## Definition of Ready – QA Perspective

- Acceptance criteria are clear.
- Dependencies are identified.
- Test data requirements are understood.
- Environment/API dependencies are available or planned.

## Definition of Done – QA Perspective

- Required test cases executed.
- Critical functionality validated.
- Defects appropriately documented.
- Fixes retested.
- Regression completed for impacted areas.
- Release risks communicated.
