# 🧪 Manual Testing Project

## 📌 Project Overview

This repository demonstrates an end-to-end Manual QA approach for a web-based e-commerce application. The project covers the complete Software Testing Life Cycle (STLC), from requirement analysis through test planning, test design, execution, defect management, retesting, regression testing and release validation.

> **Portfolio note:** All test data, defects, logs and metrics are synthetic examples created for demonstration. No production/customer information is included.

## 🎯 Testing Objectives

- Validate application functionality against business requirements
- Identify functional, usability and integration issues
- Design positive, negative and boundary test coverage
- Validate end-to-end e-commerce workflows
- Execute smoke, sanity, functional, integration and regression testing
- Validate APIs using Postman
- Track defects using Jira
- Verify fixes through retesting
- Perform risk-based regression testing
- Support release validation
