# 🧪 Manual Testing Project

## 📌 Project Overview

This repository demonstrates a real-world Manual Testing approach for a web-based e-commerce application.

The project covers the complete Software Testing Life Cycle (STLC), including requirement analysis, test planning, test scenario design, test case preparation, test execution, defect reporting, defect retesting, regression testing, and release validation.

## 🎯 Testing Objectives

* Validate application functionality against business requirements
* Identify functional and usability issues
* Verify end-to-end e-commerce workflows
* Validate positive and negative scenarios
* Ensure application stability through regression testing
* Track and document defects
* Verify fixes through retesting
* Validate critical functionality before release
