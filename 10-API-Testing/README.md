**Testing:** Positive, Negative, Boundary, Functional, Integration, Regression, Authorization, Validation

**Postman:** Collections, environments, variables, pre-request/test scripts, API chaining

## 🔐 Security Practice

Only synthetic credentials and placeholder endpoints are used. Never commit real passwords, tokens, API keys, cookies or customer information.
